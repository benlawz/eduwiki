## Launch Order Recommendation
1. **Agency Score** → Quick to make, highly shareable, creates a hook for follow-ups.  
2. **Inertia Breaker** → Instant win tool; good for repeat visits.  
3. **Motivation Map** → Adds visual + personalised depth, encourages sharing.  
4. **Resilience Reset** → Builds authority in psychology and resilience space.  
5. **Habit Autopsy** → Great “problem solver” tool for retention.  

---

## Why This Sequence Works
- **First two tools** are ultra-light builds that can live on a single page and hook people in minutes.  
- **Third and fourth** tools start introducing more *“stickiness”* — personal reports, visuals, follow-up emails.  
- **Fifth tool** creates a natural *“series”* people can explore after the first wave.  

---

## Growth Strategy: Using Tools as Funnels & Value Engines

**1. Lead Magnet Integration**
- Every tool output should include an **email opt-in** to access:
  - Detailed reports
  - “Pro” version of results
  - Customised follow-up challenges
- Example: *Agency Score* → “Enter your email to unlock your personalised growth plan.”

**2. Viral Loops**
- Include a **shareable visual summary** with each result (score badge, motivation map, resilience graph).
- Allow users to post directly to social media with a pre-written caption and link back.

**3. Retention Hooks**
- Offer **next-step tools** immediately after a result (e.g., after *Inertia Breaker*, prompt them to take *Motivation Map*).
- Create **multi-tool series** that progress users from self-awareness → action → mastery.

**4. Content Seeding**
- Publish blog/essay versions of each tool’s concept with embedded tool links.
- Use micro-snippets of results or user testimonials as social proof in posts.

**5. Community Pull**
- Allow users to compare scores anonymously to a community average.
- Host periodic “score challenges” to encourage re-testing and sharing.

**6. Segmentation**
- Tag users based on tool results so email sequences can be hyper-personalised.
- Example: low-agency score = send a 7-day agency challenge.
